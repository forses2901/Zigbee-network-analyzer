# Zigbee Network Analyzer

Веб-инструмент для локального анализа диагностических файлов ZigBee-сети: качества связей LQI, маршрутов, переходов между узлами и изменения сети во времени.

## Возможности

- загрузка одного или нескольких `.txt`, `.log`, `.dat` и `.csv` файлов;
- анализ пакетов LQI формата `AA 01 38`;
- анализ маршрутов формата `AA 01 AA`;
- граф связей с учётом значения и частоты наблюдения LQI;
- поиск подтверждённого маршрута между узлами;
- граф реальных переходов и временная динамика сети;
- сводная статистика и таблица соответствия EUI ↔ Short Address;
- сравнение двух загруженных анализов;
- локальная история и экспорт отчёта в HTML;
- светлая и тёмная темы;
- обработка данных полностью в браузере без отправки файлов на сервер.

## Использование

1. Откройте `ZBNA_v01.html` в современном настольном браузере.
2. Выберите один или несколько диагностических файлов.
3. Нажмите **Анализировать**.
4. Просматривайте результаты во вкладках LQI, маршрутов, графа переходов, статистики и динамики.

Поддерживается основной рабочий размер экрана 1920×1080. Мобильная адаптация не является функцией текущей версии.

## Формат данных

Система распознаёт два формата пакетов:

- `AA 01 38` — пакеты данных качества связи LQI;
- `AA 01 AA` — пакеты маршрутов ZigBee.

Строки без распознаваемого содержимого и неполные записи пропускаются.

## Сохранение данных

Загруженные данные сохраняются локально в браузере с помощью IndexedDB или доступного резервного браузерного хранилища. История хранится до 30 дней после последнего использования записи.

Полностью идентичные повторно загруженные файлы игнорируются как дубликаты.
